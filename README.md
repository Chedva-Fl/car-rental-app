# Car Rental App

A full-stack car rental application built with Angular and ASP.NET Web API.

## Features

- Car listing
- Car details
- Booking flow
- Payment process
- Login and registration
- Rental history

## Tech Stack

- Angular 17
- TypeScript
- ASP.NET Web API
- Entity Framework
- SQL Server LocalDB

## Project Structure

- `Frontend/`
- `Backend/`
  - `API/`
  - `BL/`
  - `DAL/`
  - `Cars.sln`

## Getting Started

### Frontend

```bash
cd Frontend
npm install
npm start
```

Open: http://localhost:4200

### Backend

Open `Backend/Cars.sln` in Visual Studio and run it with F5.

This backend is a legacy ASP.NET Web API project and works best through Visual Studio.
